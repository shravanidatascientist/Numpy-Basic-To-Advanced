# NumPy – Complete Guide (Basic to Advanced)

A structured and in-depth guide covering **NumPy concepts from basics to advanced levels**, 
focusing on array creation, manipulation, mathematical operations, and real usage patterns.

This material is intended for learners who want a **strong conceptual and practical foundation** in NumPy.

###  Array Operations

- Boolean Indexing
- Reshaping & Flattening
- Stacking & Splitting Arrays

###  Mathematical Operations
- Arithmetic Operations
- Aggregation Functions
- Axis-based Calculations
- Broadcasting

###  Advanced Usage
- Fancy Indexing
- Sorting & Searching
- Random Number Generation
- Linear Algebra Operations

##  Tools Used

- NumPy
